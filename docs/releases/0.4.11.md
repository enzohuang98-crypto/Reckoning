# v0.4.11

This release improves OpenRouter setup, AI answer retention, and engine evidence reliability.

- Validate credentials, load named free models, and verify generation before activating a connection. Report authentication, network, catalogue, and generation failures at their actual stage.
- Preserve the selected model when a refreshed catalogue no longer contains it, and require an explicit replacement.
- Keep prior AI answers and their analysis snapshot after failed or cancelled regeneration. A successful retry clears its saved retry parameters.
- Accept rule questions that identify a piece and then refer to it with a pronoun; retain clarification for unspecified moves.
- Preserve a completed exact principal variation when an interrupted deeper bound reports only the same root move. Keep its original score and depth.
- Apply dependency security patches and include IPC, setup, timeout, and PV regression checks in normal CI.

Live verification on September 9, 2026: a newly authorized OpenRouter key with a zero-dollar credit limit passed authentication, free-model discovery, and real free generation. This account check does not establish installed-client acceptance of this release. Free-model availability and rate limits are controlled by OpenRouter.

Windows signing and release promotion remain subject to the repository's release workflow. No signing requirement is disabled by this change.
