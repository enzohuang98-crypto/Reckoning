# v0.4.18

v0.4.18 fixes two board bugs and removes two settings cards that are no longer needed. The AI explanation and the engine are unchanged from v0.4.17.

## 棋盤

- Clicking an empty point without a piece selected no longer shrinks the board. The hint (for example 「請先選擇要移動的棋子」) now replaces the line above the board instead of adding a row below it.
- After clicking 「你的走法」, the board no longer stays stuck in move-picking mode. Clicking the box again, the new 「取消選擇」 button, Esc, or switching back to 「問 AI 教練」 all return the board to normal moves.

## 設定

- Removed the 「解說偏好」 card (level and language). Saved values keep working.
- Removed the 「加入本機引擎」 card. The app uses its built-in Pikafish engine; engine tests still run from the engine list, and an engine can only be removed when more than one is installed, so the app is never left without an engine.

## Verification

- Typecheck (including tests), the full test manifest, security checks and the Windows CI job passed on the release commit.

## Windows 發布門檻

- The GitHub workflow must build the installer from this exact annotated tag and verify `latest.yml`, SHA-256, public download identity, and install/uninstall behavior before Latest promotion.
- Source keeps `forceCodeSigning: true`. No trusted Authenticode credential is configured, so a stable unsigned transition release requires the workflow's exact owner acknowledgement and remains subject to Windows SmartScreen.
- Windows Server 2022 and 2025 jobs are compatibility proxies. They do not establish clean Windows 10 or Windows 11 consumer-client acceptance.
