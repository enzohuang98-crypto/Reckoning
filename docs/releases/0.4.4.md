# v0.4.4

v0.4.4 修正 Gemini 金鑰測試遇到暫時性 503 時的處理，並讓局面分析與右鍵引擎主線重播維持不中斷更新。

## Gemini 503

- Google Gemini 的 `503 UNAVAILABLE` 代表模型服務暫時過載或不可用，不是 API 金鑰認證失敗。
- 金鑰測試遇到 503 時，會在原有 30 秒總時限內依序等待 0.5 秒、1 秒，最多重試兩次。
- 重試成功即正常完成驗證；持續 503 時會明確說明服務過載，且不再提示使用者檢查金鑰。
- 401／403 認證與權限錯誤、429 限流、503 暫時不可用仍分別處理，不會互相混淆。

## 持續局面分析

- 引擎搜尋期間會即時傳送每一條 MultiPV 候選的排名、UCI 主線、中文主線、分數與深度，不再只傳第一線。
- 右鍵「查看引擎想法」保持開啟時，第一線、第二線、第三線會跟隨引擎新深度持續更新，前後步重播使用最新主線。
- 走一步切換局面時，局面分析先保留上一筆畫面並標示正在分析新局面；第一筆新深度到達後原位替換，不再出現整塊空白。
- 保留畫面只用於避免視覺中斷；AI 解說仍只會使用與目前 FEN、著法完全相符的新分析結果。

## Windows 發布邊界
