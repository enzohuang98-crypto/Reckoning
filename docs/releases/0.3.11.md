# v0.3.11

v0.3.11 is a teacher-test candidate revision that closes the newly reported `js-yaml` dependency advisory before the next candidate build.

## Security maintenance

- Updates the lockfile resolution of `js-yaml` from `4.3.0` to `4.3.1`, the available non-breaking remediation for [GHSA-5p4m-2wfm-xmqj](https://github.com/advisories/GHSA-5p4m-2wfm-xmqj) / CVE-2026-59870.
- The package is reachable through `electron-updater` at runtime and through the `electron-builder` build chain; `npm run security:audit` requires zero moderate-or-higher runtime findings and no safe-to-fix build-tool findings.
- The candidate remains intentionally unsigned and must not be promoted to Latest. Its release asset SHA must be recorded independently after the new workflow completes.

## Scope

This revision does not claim that the external teacher pilot is complete. The three teacher-confirmed cases, two real-machine runs, external 1–5 rubric, three gates, temporary-key zero-residue check, clean Windows 10/11 evidence, and trusted signing remain separate acceptance requirements.
