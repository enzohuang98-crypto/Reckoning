# v0.4.15

v0.4.15 replaces the AI explanation pipeline with a simpler, checked design: the program computes the chess facts, the model only explains them, and every answer is checked before it is shown. It also fixes AI connections behind antivirus HTTPS scanning and removes several unused subsystems.

## AI 解說（v2）

- A fact table is computed by replaying the engine lines: captures and checks, new threats with the file of each piece and which piece can recapture, per-line capture totals, unfinished exchanges, only-legal moves, checkmate/stalemate and the full piece list in endgames. Evaluations are shown in pawns from the side to move.
- The model writes a short plain-text explanation from those facts only. Answers are checked for moves that do not exist, captures or checks that contradict the facts, a non-only move described as forced, wrong side to move, leaked internal formats and truncation. A failed answer gets one repair; if it still fails, an engine summary (not AI-generated) is shown with the reason.
- Meaning-preserving tidying before the check (prompt labels, mixed-numeral moves) avoids discarding correct answers.
- Budget: at most 3 model calls, 60 s each, 110 s in total. Rule questions such as “is this move legal” are answered by the rules engine without a model call.
- `XQA_EXPLAIN_PIPELINE=v1` still rolls back to the previous pipeline.

## Models and connections

- OpenRouter: up to two user-approved `:free` backup models; the answer shows which model replied and why another was skipped.
- The OpenRouter model list also offers two paid models vetted on real PlayOK positions, Claude Sonnet 5.5 and Claude Haiku 5.5, labelled as paid. Other paid models and automatic routers stay hidden.
- The app trusts the Windows root certificate store, so AI requests work when antivirus software (for example Kaspersky HTTPS scanning) re-signs connections. Certificate failures are explained instead of retried.
- A dropped connection is retried once; a short per-minute rate limit without a backup is retried once after the service's suggested wait. Gemini errors now carry the status and quota kind, so a daily quota shows the right message.
- Diagnostics record each model call (kind, duration, failure category and, for network failures, the underlying code) without prompts, answers or keys.

## Removed

- Buy-out licence, teacher-test and dual-engine verification subsystems, and the harness tuning settings page. Diagnostics export and clearing moved to 「資料與系統」.

## Verification

- Typecheck (including tests), the full test manifest, security checks and the Windows CI job passed on the release commit.
- Live checks on the user's machine (P3-9): with Claude Sonnet 5.5 on held-out real PlayOK positions, all 5 completed answers scored 4 or higher in a manual review; free and low-cost models scored lower and are subject to OpenRouter rate limits. The remaining held-out positions were not run because the test account ran out of credit.

## Windows 發布門檻

- The GitHub workflow must build the installer from this exact annotated tag and verify `latest.yml`, SHA-256, public download identity, and install/uninstall behavior before Latest promotion.
- Source keeps `forceCodeSigning: true`. No trusted Authenticode credential is configured, so a stable unsigned transition release requires the workflow's exact owner acknowledgement and remains subject to Windows SmartScreen.
- Windows Server 2022 and 2025 jobs are compatibility proxies. They do not establish clean Windows 10 or Windows 11 consumer-client acceptance.
