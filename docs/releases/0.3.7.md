# 象棋 AI 分析講解 v0.3.7

v0.3.7 修正「明明已經發布新版，桌面 App 卻好像永遠不會自動更新」的問題。更新機制本身一直是好的，
問題在於**使用者根本看不到它**，而且長時間開著的 App 不會重新檢查。

## 主要改善

- **有新版時會在標題列主動提示**：先前更新狀態只顯示在「設定 → 系統」頁面內，
  使用者不主動點進那一頁就完全不會知道有新版可用，實際體感等同沒有自動更新。
  現在偵測到新版（或更新已下載待安裝）時，標題列會出現一個提示，點擊直接跳到設定頁完成下載／安裝。
  沒有新版時完全不渲染，畫面與先前一模一樣。
- **改為定期重新檢查**：先前只在啟動後 5 秒檢查一次，之後不再檢查；
  習慣把 App 一直開著的使用者永遠不會發現後來發布的版本。現在除了啟動後的首次檢查，
  之後每 4 小時會再檢查一次。
- **修正重新檢查會覆蓋已下載狀態**：加上防護，正在檢查／下載中或已下載待安裝時不重跑檢查，
  避免剛下載好的更新按鈕因為背景重新檢查而變回「可下載」。
- **API 金鑰測試改成真的跑模型**：不再用「列出模型」假裝已驗證。OpenAI、Anthropic、Gemini
  與相容服務都會用所選模型完成一次極短推論；沒有模型權限、金鑰錯誤或服務逾時，會直接顯示在
  該模型旁邊，不會動到其他已儲存金鑰。
- **模型選單跟上目前文字模型**：補齊 OpenAI、Claude 與 Gemini 現行文字輸出模型；
  供應商剛開放、尚未列入選單的模型，也可以貼入正式 model ID。GPT-5.6 與 OpenAI Pro
  系列會走 Responses API，其餘模型依各自支援的請求格式送出。
- **刪除金鑰不再跳出阻塞視窗**：改成設定頁內的二次確認，取消或刪除完成後仍可繼續操作。

## 仍維持手動確認

自動下載仍然**刻意保持關閉**（`autoDownload = false`）：程式只會自動偵測並提示，
實際下載與安裝一律由使用者按下按鈕決定，不會在背景偷偷下載或自行重啟。

## 不受影響的範圍

- 引擎判斷邏輯、AI 解釋 Prompt、Harness 品質迴圈與雙引擎裁決規則均未變更。
- 分析頁已驗收的版面比例未變動：標題列提示為 `flex: 0 0 auto`，不與分析工具列
  （`.analysis-command-mount`，維持 `flex: 1`）搶伸縮空間，且只在有新版時才存在。

## Windows 發布門檻

v0.3.7 沒有未簽章發行選項。候選安裝檔必須有受信任的 Authenticode 簽章與時間戳，
並由乾淨的 Windows 10 22H2、Windows 11 x64 用戶端各自完成瀏覽器下載、安裝、啟動、
Pikafish 搜尋、捷徑與解除安裝驗收。兩份證據對不上同一個 SHA-256 時，版本不會升為 Latest。
兩份驗收紀錄還必須對上本次 tag、commit 與 workflow run，原始文件 digest 也要和受保護環境中的值完全一致；過期或被改過的紀錄不能放行。
