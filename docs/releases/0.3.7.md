# 象棋 AI 分析講解 v0.3.7

v0.3.7 修正「明明已經發布新版，桌面 App 卻好像永遠不會自動更新」的問題。更新機制本身一直是好的，
問題在於**使用者根本看不到它**，而且長時間開著的 App 不會重新檢查。

## 主要改善

- **有新版時會在標題列主動提示**：先前更新狀態只顯示在「設定 → 系統」頁面內，
  使用者不主動點進那一頁就完全不會知道有新版可用，實際體感等同沒有自動更新。
  現在偵測到新版（或更新已下載待安裝）時，標題列會出現一個提示，點擊直接跳到設定頁完成下載／安裝。
  沒有新版時完全不渲染，畫面與先前一模一樣。
- **改為定期重新檢查**：先前只在啟動後 5 秒檢查一次，之後不再檢查；
  習慣把 App 一直開著的使用者永遠不會發現後來發布的版本。現在除了啟動後的首次檢查，
  之後每 4 小時會再檢查一次。
- **修正重新檢查會覆蓋已下載狀態**：加上防護，正在檢查／下載中或已下載待安裝時不重跑檢查，
  避免剛下載好的更新按鈕因為背景重新檢查而變回「可下載」。

## 仍維持手動確認

自動下載仍然**刻意保持關閉**（`autoDownload = false`）：程式只會自動偵測並提示，
實際下載與安裝一律由使用者按下按鈕決定，不會在背景偷偷下載或自行重啟。

## 不受影響的範圍

- 引擎判斷邏輯、AI 解釋 Prompt、Harness 品質迴圈與雙引擎裁決規則均未變更。
- 分析頁已驗收的版面比例未變動：標題列提示為 `flex: 0 0 auto`，不與分析工具列
  （`.analysis-command-mount`，維持 `flex: 1`）搶伸縮空間，且只在有新版時才存在。

## 已知限制

v0.3.7 尚未配置受信任 CA 核發的 Windows 程式碼簽章，Windows SmartScreen 可能顯示警告。
這需要外部簽章憑證才能解除；本專案不以自簽憑證冒充公開信任。
