# v0.4.9

v0.4.9 修正即時局面分析的候選著排序，並簡化首頁右上角的分析切換介面。

## 穩定的候選著順序

- 局面分析改以 Pikafish 的 MultiPV 候選順位排列：第 1 候選永遠在第一列、第 2 候選在第二列。
- 排序不再使用回報先後或分數數值，紅方正分與黑方負分都會依引擎候選順位顯示。
- 搜尋加深時，同一候選著會更新原本的列；不再累積舊深度資料造成順序跳動。

## 首頁介面

- 右上角移除「AI 教練」切換欄位，只保留「猜著」。
- AI 分析內容與猜著功能均保留；按「猜著」可切換到猜著，再按一次可回到分析內容。

## 驗證與發布邊界

- 新增紅方、黑方與搜尋加深三組候選排序回歸測試。
- 完整測試、TypeScript 型別檢查與 production build 均通過。
- 本版延續既有 Windows 發布門檻；未簽章安裝包必須明確標示 `NotSigned`，並通過版本、SHA、安裝、卸載與公開下載驗證。Windows Server 驗證不等同真實 Windows 10 或 Windows 11 消費者電腦證據。
