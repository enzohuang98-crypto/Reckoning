# v0.4.23

v0.4.23 重新整理介面：換成深藍配色、工具列分組並加上文字、AI 回答分段顯示，版面讓棋盤與回答更大。內含 v0.4.22 的所有修正。

## 下載與安裝（給第一次使用的人）

- **系統需求：** Windows 10 或 Windows 11（64 位元）。不支援 Windows 7／8.1、32 位元 Windows、macOS 與手機。
- **下載：** 在本頁下方「Assets」點 `xiangqi-analyzer-…-setup.exe`（約 170 MB）。其他檔案是自動更新與檔案驗證用，不需要下載。
- **Windows 安全性警告：** 這個安裝檔沒有付費的程式碼簽章，Windows 會顯示「Windows 已保護您的電腦」。請按「其他資訊」→「仍要執行」。若電腦開啟了 Windows 11 的「智慧型應用程式控制」，或是學校、公司統一管理的電腦，可能會直接擋下安裝，這時請改用個人電腦。
- **安裝：** 安裝時選「只為我安裝」，不需要系統管理員權限。
- **引擎分析：** 內建象棋引擎皮卡魚，裝好即可分析，不需要網路。
- **AI 文字解說：** 需要自己的 AI 服務金鑰。沒有金鑰時，引擎分析照常可用，只是沒有 AI 文字解說。建議使用 OpenRouter 的付費模型 Claude Sonnet 5.5，免費模型的解說品質明顯較差，也常因限流而無法回答。
  1. 到 openrouter.ai 註冊，在 Credits 頁面儲值少量金額（例如 5 美元）。
  2. 在 Keys 頁面建立一把金鑰；可以替這把金鑰設定花費上限，避免意外超支。
  3. 開啟本程式，到「設定 → AI 與金鑰」貼上金鑰，按「自動連線」。
  4. 在模型清單選名稱含「Claude Sonnet 5.5」、標示「付費」的那一項，按「驗證並使用此模型」。
  5. 實測每次解說約新台幣 0.5 元，依局面與追問次數而異。金鑰以 Windows 加密保存在本機，只會送到 OpenRouter 用來呼叫模型。

## 介面

- **配色：** 主色從綠色改為深藍。中性色都帶一點藍灰，木色只用在棋盤，紅色只留給紅方棋子與錯誤訊息。棋盤上的引擎箭頭改用藍色，在木色棋盤上更清楚。
- **工具列：** 按鈕分成四組（局面工具／悔棋與下一步／分析／檢視），每組一個框。每顆按鈕是「圖示＋兩到四字標籤」，寬度一致。視窗窄於 1180 像素時才收成只有圖示。
- **AI 回答：** 回答依原本的換行分段，「- 」開頭的行變成條列，**粗體小標**正常顯示。之前整段擠在一起，還會露出星號。
- **版面：**
  - 寬視窗下，棋盤卡片的寬度跟著可用高度走，棋盤會撐滿卡片，其餘寬度都給「問 AI 教練」。
  - 底部「局面分析」表調矮。想法與問題兩個欄位並排，回答多出可見空間。
- **放大棋盤：** 改成收起底部的局面分析表，讓棋盤和教練欄用滿整個畫面高度。分析資料仍可從工具列的「分析資料」打開。
- **匯入棋局：** 打開時，面板放在棋盤右邊，可以一邊點棋譜一邊看棋盤。棋盤不會再被擠小。
- **擺棋工具：** 打開時，棋盤一樣跟著高度縮放，不會被切掉。
