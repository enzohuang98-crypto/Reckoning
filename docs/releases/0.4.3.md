# v0.4.3

v0.4.3 修正 Gemini 金鑰已可連線，但測試模型因 thinking token 用完短輸出預算而沒有返回可見文字的情況。其他功能不變。

## Gemini 金鑰驗證

- 首次金鑰測試仍使用 32 個輸出 token，維持快速、低成本的健康檢查。
- 若 Gemini 明確回傳 `MAX_TOKENS`，或回應包含 thinking token 但沒有可見文字，會在同一個 30 秒總時限內以 256 個輸出 token 重試一次。
- 最多只重試一次，不會無限呼叫 API。
- 若 Google 回傳 `SAFETY` 等提示阻擋原因，不會重試，也不會把 HTTP 200 誤判成驗證成功；畫面會顯示實際原因。
- API 金鑰仍只透過 `x-goog-api-key` Header 傳送，不寫入 URL、測試資料、提交內容或發布紀錄。

## Windows 發布邊界

本版本延續現有 GitHub Release 門檻；未簽章候選安裝包必須明確標示 `NotSigned`，並通過版本、SHA、安裝、卸載與公開下載驗證。Windows Server 驗證不等同真實 Windows 10 或 Windows 11 消費者電腦證據。
