# v0.4.6

v0.4.6 修正「實戰步與 AI 首選比較」在 Gemini 或其他 AI 教練模型逾時、503、無效 JSON 或內容不合格時，錯把固定的引擎摘要當成完成解說的問題。

## 可信的實戰步解說

- 一鍵比較會先檢查主線是否足以支持因果說明：AI 首選至少兩手、實戰步至少三手。
- 若既有快照過短，會先做一次最多五秒的引擎加深；仍不足時直接提示使用者讓局面分析多運行幾秒後再重試，而不是要求模型憑空補完。
- 刪除模型失敗時的固定五段模板與補字邏輯。逾時、模型額度用盡、無效 JSON 或品質驗證失敗都會顯示明確、可重試的錯誤，trace 也會正確記為 `failed`。
- 合格但偏短的模型答案仍只能用同一份已驗證引擎證據補足，不能新增未被主線支持的棋理或戰術。

## Gemini 與暫時性服務錯誤

- 一鍵 AI 解說的畫面總期限調整為 120 秒；初始模型階段最多 100 秒。
- HTTP 503 只會在剩餘至少 30 秒時自動重試一次；429 限流不會立即重試，避免繼續耗用或撞擊額度。
- 503 與其他 5xx 會顯示安全、可理解的狀態分類，不會回傳 Provider 原始錯誤、API Key 或內部資料。

## 驗證與發布邊界

- 回歸測試覆蓋短主線、503、逾時、限流、無效／空泛回答與 trace 狀態。
- 本版延續既有 Windows 發布門檻；未簽章安裝包必須明確標示 `NotSigned`，並通過版本、SHA、安裝、卸載與公開下載驗證。Windows Server 驗證不等同真實 Windows 10 或 Windows 11 消費者電腦證據。
