# v0.4.12

## Question-focused coach answers

- Answer supported pawn movement and side-to-move questions from the current board and legal move rules, without waiting for an AI provider.
- Route specific first questions through the concise question-answer flow, while preserving full position explanations and frozen teacher comparisons.
- Request JSON output explicitly from OpenRouter when the harness needs structured output.
- Recover malformed or off-topic follow-up answers with a bounded, question-focused prose request using the selected model and existing call/token budget.
- Wait for the current engine analysis to complete before starting the model, and obtain a completed principal variation when the captured line is too short. Cancelled or failed engine work does not trigger an answer from an older snapshot.
- Keep the model's explanation tied to Pikafish moves and board facts; do not substitute independent strategic judgment or hypothetical continuations.
- Preserve cancellation and previous-answer retention when the provider cannot return a usable answer. Relevance checks screen known question topics; they do not prove arbitrary strategic claims.

The release also includes the v0.4.11 credential diagnostics, retry/retention, complete principal-variation preservation, and dependency fixes. Windows signing and installed-client acceptance remain separate release requirements.
