# v0.4.10

v0.4.10 新增 OpenRouter 免費模型的即時選擇流程，並重寫 README，讓目前功能、更新方式與安全邊界都能直接對照原始碼與正式發布流程。

## OpenRouter 免費模型

- 設定頁與首次設定流程現在可直接貼上 OpenRouter API Key，讀取官方即時免費模型清單後再由使用者選擇要綁定的具體模型。
- 後端只會把請求送到使用者實際選定的完整 OpenRouter 模型 ID，不再接受隨機免費路由，也不會讓 UI 顯示的模型名稱和後端實際呼叫目標分離。
- 金鑰驗證與測試流程會先確認目前帳號可用的免費文字模型，再以所選模型進行實際低輸出測試，避免把錯 provider、過期模型或路由錯配誤判成設定成功。

## 文件與架構說明

- README 依目前產品行為重寫，整合棋盤分析、PV 重播、AI 解說、提供者設定、自動更新與 Windows 發布邊界。
- 新版 README 明確寫出 renderer、preload、main、SecretStore 與 GitHub Release 更新通道的責任分界，方便後續維護與驗證。

## 驗證與發布邊界

- OpenRouter provider、IPC 綁定、金鑰辨識、SecretStore 與 renderer 選單的回歸測試已補齊。
- 完整測試、TypeScript 型別檢查、dependency audit 與 production build 均通過後才進入 tag 與 Release workflow。
- 正式公開版是否可升為 Latest，仍取決於既有 Windows 發布流程中的簽章與 client evidence gate；GitHub Actions 的 Windows Server 驗證不等同真實 Windows 10 或 Windows 11 用戶端證據。
