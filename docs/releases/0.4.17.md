# v0.4.17

v0.4.17 stops the AI from guessing which move a question is about. It includes the v0.4.16 interface fixes.

## AI 解說

- A question only carries the player's move when the move has been submitted in 「猜著練習」 or clicked in an imported game. When no move is attached and the question asks about "my move" or "this move", the AI now says it did not receive the move and how to pick it, instead of answering about a candidate move as if the player had played it. Questions with a move attached are unchanged.

## 分析頁（v0.4.16）

- 「問 AI 教練」 and 「猜著練習」 are shown side by side with the active mode highlighted and a one-line hint; in 「猜著練習」 the question box appears only after the guess is submitted.
- The OpenRouter settings no longer warn that the selected model left the list before the list has been loaded.

## Verification

- Typecheck (including tests), the full test manifest, security checks and the Windows CI job passed on the release commit.
