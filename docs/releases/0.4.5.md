# v0.4.5

v0.4.5 修正有效 Gemini 金鑰因測試模型生成卡住而被誤判逾時，以及右鍵「查看引擎想法」在 MultiPV 候選重新排名或改寫主線時跳到其他局面的問題。

## Gemini 金鑰驗證

- 自動設定會呼叫 Google 官方 `models.list`，以實際 HTTP 認證結果、帳號可見模型及 `generateContent` 能力宣告作為儲存閘門。
- 不再額外要求測試模型產生 `OK` 才儲存金鑰，避免有效金鑰因單次模型過載、thinking 或生成停滯而被誤判失敗。
- 自動設定只呼叫一次模型清單；直接測試指定 Gemini 模型時也只使用模型清單，不會暗中產生文字或消耗生成額度。
- 只有官方清單中實際可見且支援文字生成的穩定模型可以被自動綁定；不會把金鑰綁到錯誤模型。
- 補齊官方穩定版 `gemini-3.7-flash` 的內部 Registry 與設定選項，使自動選模結果可直接用於正式解說；保留既有 Gemini 3.5 預設值不變。
- 模型清單遇到 408、429、網路暫時錯誤或 5xx 時，會在同一個有限時限內最多退避重試兩次。
- API 金鑰仍只透過 `x-goog-api-key` Header 傳送，不寫入 URL、日誌、測試資料、提交或 Release。

## 穩定的引擎主線重播

- 右鍵重播視窗改以根著 UCI move 追蹤使用者選中的主線，不再用會隨 MultiPV 排名改變的陣列索引。
- 第一線、第二線、第三線互換排名時，選中的主線會跟著同一個根著移動，不會突然切到另一條候選線。
- 使用者已走到某一步時，只有不改寫已觀看前綴的即時更新才會套用；引擎若改寫前面的著法，棋盤會保持當前局面，避免在眼前跳動。
- 回到起始局面或重新選擇候選線後，重播會接上最新的引擎主線；同一條線後方新增的著法仍可持續顯示。
- 切換到全新棋盤局面時會重設重播狀態，避免舊局面的主線套到新棋盤。

## Windows 發布邊界

本版本延續現有 GitHub Release 門檻；未簽章安裝包必須明確標示 `NotSigned`，並通過版本、SHA、安裝、卸載與公開下載驗證。Windows Server 驗證不等同真實 Windows 10 或 Windows 11 消費者電腦證據。
