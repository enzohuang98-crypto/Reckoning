# v0.4.16

v0.4.16 is a small interface fix release on top of v0.4.15. The AI explanation pipeline, models and engine are unchanged.

## 分析頁

- The analysis panel now shows its two modes side by side, 「問 AI 教練」 and 「猜著練習」, with the current mode highlighted and a one-line hint. Before, a single 「猜著」 toggle looked like a heading and it was unclear which mode was active or where to type.
- In 「猜著練習」, the question box stays hidden until the guess is submitted, so there is only one place to type at a time. After submitting, follow-up questions work as before.

## 設定

- The OpenRouter section no longer shows 「目前選擇的模型已不在最新清單」 before the model list has been loaded. The warning now appears only when a loaded list really lacks the selected model. The model in use (「目前使用中」) was never affected.

## Verification

- Typecheck (including tests), the full test manifest, security checks and the Windows CI job passed on the release commit.

## Windows 發布門檻

- The GitHub workflow must build the installer from this exact annotated tag and verify `latest.yml`, SHA-256, public download identity, and install/uninstall behavior before Latest promotion.
- Source keeps `forceCodeSigning: true`. No trusted Authenticode credential is configured, so a stable unsigned transition release requires the workflow's exact owner acknowledgement and remains subject to Windows SmartScreen.
- Windows Server 2022 and 2025 jobs are compatibility proxies. They do not establish clean Windows 10 or Windows 11 consumer-client acceptance.
