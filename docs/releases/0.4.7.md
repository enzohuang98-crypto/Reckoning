# v0.4.7

v0.4.7 改善 Windows 自動更新流程：使用者在新版通知中確認一次後，程式會完成下載、安裝與重新啟動，不必再前往設定頁按第二次更新按鈕。

## 一次確認完成更新

- 發現新版時顯示專用更新視窗，不再使用只有 OK／取消的系統確認框。
- 選擇「立即更新」後才會下載；下載完成會自動安裝並重新開啟 Reckoning。
- 未經使用者確認的下載完成事件不會擅自重新啟動，設定頁仍保留「重新啟動並安裝」作為手動入口。

## 更新提醒選擇

- 「稍後提醒我」會暫停該版本通知，四小時後再次詢問；重新啟動程式後仍保留提醒時間。
- 「跳過此版本」只停止該版本的自動通知；下一個較新版本仍會正常提醒。
- 跳過或稍後提醒不會移除設定頁的立即檢查、下載更新與手動安裝功能。

## 驗證與發布邊界

- 新增主行程更新狀態測試，驗證使用者同意後會呼叫 `quitAndInstall(false, true)`，未同意時不會安裝。
- 更新視窗回歸測試覆蓋三個選項、四小時提醒、跳過單一版本、新版本重新提醒，以及手動入口保留。
- 本版延續既有 Windows 發布門檻；未簽章安裝包必須明確標示 `NotSigned`，並通過版本、SHA、安裝、卸載與公開下載驗證。Windows Server 驗證不等同真實 Windows 10 或 Windows 11 消費者電腦證據。
