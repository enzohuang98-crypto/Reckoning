# v0.4.2

v0.4.2 让自动更新在下载前取得使用者同意，并修正 Gemini 金钥验证过早逾时与模糊错误讯息。

## 自动更新询问

- 程式仍会在启动后自动检查更新，并每隔四小时重新检查。
- 发现新版本时会主动弹出确认通知；只有选择更新后才开始下载。
- 选择稍后不会下载，同一个版本在同一次启动中不会重复询问。
- 设定页保留手动检查与下载按钮；下载完成后仍须明确选择重新启动并安装。

## Gemini 金钥验证

- 官方模型实际生成验证由 8 秒调整为有限的 30 秒，给首次 Gemini thinking 请求合理回应时间。
- 整体金钥自动连线上限同步调整为 45 秒，避免 renderer 先于 Provider 验证中断。
- Gemini 已连线但测试模型没有返回文字时，改为明确说明该状态，不再归类成未知错误。
- 金钥仍只透过 `x-goog-api-key` Header 传送，并沿用 `AIza`、`AQ.` 与日志遮蔽保护。

## Windows 发布边界

本版本延续现有 GitHub Release 门槛；未签章候选安装包必须明确标示 `NotSigned`，并通过版本、SHA、安装、卸载与公开下载验证。Windows Server 验证不等同真实 Windows 10 或 Windows 11 消费者电脑证据。
