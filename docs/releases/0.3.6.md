# 象棋 AI 分析講解 v0.3.6

v0.3.6 修正使用者實測回報的「新增 API 金鑰時整個視窗會卡住沒有回應」問題，並補上金鑰健康檢查、分數顯示一致性與 App 內部品牌名稱統一。

## 主要改善

- **金鑰儲存不再卡住視窗**：`SecretStore` 與共用的 `SecureJsonFile` 工具改用
  `node:fs/promises`，移除會強制 fsync 的同步磁碟寫入（`writeFileSync(..., { flush: true })`）。
  這段同步 I/O 先前執行在 main process 的訊息迴圈上，會讓整個視窗（不只設定頁）在儲存、
  啟用或刪除 API 金鑰時失去回應。
- **新增／刪除金鑰有明確等待狀態與逾時保護**：設定頁的金鑰操作與初次狀態讀取現在會顯示
  「處理中…」並套用既有的 10 秒逾時保護，逾時會顯示明確錯誤而不是無限卡住。
- **新增「測試金鑰」**：可在儲存前（草稿金鑰，不落地）或針對已存的每筆金鑰個別驗證是否真的能
  通過對應 AI 服務的驗證，不會消耗生成 token。同時修正 `detectApiKeyProvider`：即使已指定
  provider，仍會依已知金鑰前綴做基本格式檢查，擋下明顯貼錯欄位的金鑰。
- **分數顯示不再自相矛盾**：局面分析結果與猜著比較畫面統一以 `+1.20` 這類格式化分數
  （`score.displayText`）為主要顯示，不再把原始 UCI 字串標成「原始分數」跟它並列。
- **App 內部品牌名稱統一**：啟動畫面、初始設定精靈與主畫面標頭原本各自顯示「象理」／
  「XIANGLI」／「XIANGQI STUDY DESK」三種不同名稱，現在統一為「象棋 AI 分析講解」，
  與安裝檔、官網一致。

## 不受影響的範圍

- 引擎判斷邏輯、AI 解釋 Prompt、Harness 品質迴圈與雙引擎裁決規則均未變更。
- Engine registry、License、AppData 與 Harness trace 的儲存路徑維持原本同步實作；
  這次的範圍刻意收斂在實際造成回報問題的 SecretStore 路徑上。
- 棋盤、前端工作區版面比例與既有 CSS 尺寸均未調整，僅新增元件（測試金鑰按鈕、忙碌提示）
  與更新文字內容。

## 已知限制

v0.3.6 尚未配置受信任 CA 核發的 Windows 程式碼簽章，Windows SmartScreen 可能顯示警告。
這需要外部簽章憑證才能解除；本專案不以自簽憑證冒充公開信任。
