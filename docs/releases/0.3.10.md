# 象棋 AI 分析講解 v0.3.10

v0.3.10 是 teacher-test candidate 的操作可追溯性修正版。它把 teacher-test run manifest 的完整身份欄位顯示在 Settings 的 active run 畫面，讓受測者能直接核對 App version、release tag、product source commit、installer filename／SHA-256 與 Windows runtime。它也把外部 rubric 文件校正為原始 pilot 計畫要求的七個 1–5 評分維度與三個獨立驗收 gate。

## 主要改善

- Settings active teacher-test run 顯示完整 artifact identity，不只顯示 tag 與 installer hash。
- 新增 renderer regression test，鎖定 App version、release tag、source commit、installer 與 Windows runtime 都會出現在畫面文字中。
- teacher-test protocol 與 learning-history draft 使用七個 1–5 維度：最佳／實戰步判斷、變化合法性、evidence 忠實度、棋理因果清楚度、可執行練習、反思引導、學習歷程適切性。
- 將 `softwareEnvironment`、`xiangqiContent`、`teachingValue` 明確列為獨立 `pass`／`concern`／`fail`／`not_assessed` gates，不由單題分數自動推導。

## 證據解讀

v0.3.10 仍是 teacher-test candidate，不代表老師雙機實測、三個 teacher-confirmed cases、臨時 API Key 零殘留、Windows 10／11 clean-client evidence、正式簽章或 Latest promotion 已完成。v0.3.9 的 tag、Release 與 installer 不覆寫，仍保留為歷史候選證據。

## Windows 發布門檻

Release workflow 的 `teacher-candidate` 模式仍刻意產出未簽章 prerelease，永遠不升為 Latest；`formal-release` 才要求受信任 Authenticode 簽章、時間戳與獨立 Windows 10 22H2／Windows 11 client evidence。Server proxy、typecheck、unit test、engine E2E 或本機乾跑都不能取代 clean-client 或真人教師門檻。
