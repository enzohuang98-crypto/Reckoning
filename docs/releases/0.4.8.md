# v0.4.8

v0.4.8 簡化首頁猜著與 AI 分析流程，並補齊局面分析和輸入欄位的文字選取、複製與貼上操作。

## 文字複製與貼上

- 局面分析表格的分數、深度、時間、節點、候選著與主線可以用滑鼠框選及複製。
- 選取一般文字後按右鍵會提供複製與全選；輸入欄位按右鍵會提供復原、重做、剪下、複製、貼上與全選。
- 「為什麼想走這步？（選填）」在提交前可正常輸入與貼上；提交後仍可選取及複製已保存的內容。

## 猜著直接進入完整分析

- 提交猜著後直接切換到 AI 教練並自動執行完整研究，不再停留在獨立的準確、緩手或失誤判定畫面。
- 引擎首選、棋手著法、錯誤等級、分數差與雙方主線仍保留在分析證據中，由完整 AI 解說統一說明。
- 設定頁移除「解說品質」分類；產品固定使用完整研究、分析完成後自動解說，以及追問沿用既有證據。
- 舊版保存的相關開關會在讀取時正規化為固定策略，不會因升級而繼續停用自動解說。

## 驗證與發布邊界

- 新增回歸測試，覆蓋 Electron 文字右鍵選單、局面分析選取、猜著直接導向與固定解說策略。
- 完整測試、TypeScript 型別檢查、production build 與相依套件安全稽核均通過。
- 本版延續既有 Windows 發布門檻；未簽章安裝包必須明確標示 `NotSigned`，並通過版本、SHA、安裝、卸載與公開下載驗證。Windows Server 驗證不等同真實 Windows 10 或 Windows 11 消費者電腦證據。
