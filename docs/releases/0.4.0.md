# v0.4.0

v0.4.0 集中修正桌面版分析、AI 连线与更新体验。

## 使用者可见变更

- 局面分析的普通评估改为整数 centipawn（例如 `+125 cp`），杀棋距离显示维持原语义。
- 移除错题本与待理解局面的导航、页面与新增动作；旧版资料首次读取时先备份到 `retired-study-data-v1.json`，再迁移到 schema v2。
- 分析区文字现在可直接框选、复制与贴上。
- 在主棋盘按滑鼠右键可选择「查看引擎想法」，以小棋盘逐手前进、后退，并切换 MultiPV 候选主线。
- AI 设定简化为单一 API Key 栏位。后端会自动辨识 OpenAI、Anthropic 或 Gemini，读取帐号实际可用模型、执行一次真实生成验证，成功后才加密储存并设为使用中。
- 更新检查发现新版后自动下载；下载完成后必须由使用者明确确认「重新启动并安装」。一般关闭程式不会自动安装。

## Windows 发布门槛

此档只定义产品变更，不声称安装档已经可信发布。正式 GitHub Release 仍须通过既有 release workflow 的版本、签章、安装档 smoke test、SHA 与发布证据门槛；任何缺少的外部门槛不得以单元测试替代。
