# v0.3.12

v0.3.12 fixes the two user-reported desktop issues in AI credential setup and Pikafish evaluation display.

## AI credential setup

- Replaces the disabled empty active-model selector with an actionable `新增模型金鑰` link.
- The link moves directly to the encrypted credential form; once a compatible credential exists, the normal active-model selector returns.
- Local keyless models remain separate from API credentials, and no API key is committed or uploaded.

## Pikafish score scale

- Detects whether a UCI engine advertises Pikafish's `PawnValueNormalized` score type.
- Selects that score type before analysis so the existing display contract remains one pawn = 100 centipawns (`+1.00`).
- Leaves UCCI engines and UCI engines without this advertised option unchanged.

## Security maintenance

- Updates the transitive `nanoid` lockfile resolution from `3.3.16` to `3.3.18`, closing `GHSA-2v37-7h3g-55p8` without adding a direct dependency.

## Windows release boundary

- The GitHub Actions release build remains intentionally unsigned because trusted Authenticode signing material is not configured in the repository environment.
- The installer, blockmap, `latest.yml`, and `SHA256SUMS.txt` must come from the same successful workflow run and be read back before in-app update testing.
- Publishing these exact unsigned bytes as Latest for the requested in-app update does not prove trusted signing, independent clean Windows 10/11 validation, or external teacher validation.
