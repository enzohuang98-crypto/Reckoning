# v0.4.1

v0.4.1 修正皮卡魚分數顯示與 Google Gemini 新型 API Key 相容性。

## 皮卡魚分數顯示

- 局面分析直接顯示皮卡魚輸出的整數 centipawn 分數，例如 `42`、`-42` 與 `0`。
- 正分不再加上 `+`，也不再顯示 `cp` 後綴；殺棋距離與既有分數視角維持不變。
- 錯棋判定仍使用既有內部兵值門檻，不因顯示格式改變而改變分類結果。

## Gemini API Key

- 單一 API Key 欄位現在同時辨識舊的 `AIza` 標準型金鑰與新的 `AQ.` 授權型金鑰。
- Gemini 金鑰仍只透過 `x-goog-api-key` Header 傳送，不會進入請求 URL。
- 日誌遮蔽同步支援 `AQ.` 金鑰，避免新型金鑰意外出現在日誌。
- Claude、OpenAI、模型選擇、加密儲存與其他設定行為維持不變。

## Windows 發布門檻

此檔只定義產品變更，不聲稱安裝檔已具受信任簽章。正式 GitHub Release 仍須通過既有 release workflow 的版本、簽章、安裝檔 smoke test、SHA 與發布證據門檻；任何缺少的外部門檻不得以單元測試替代。
